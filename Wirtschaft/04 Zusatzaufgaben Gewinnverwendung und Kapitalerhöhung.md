# Zusatzaufgaben: Gewinnverwendung und Kapitalerhöhung

Zurück zu [[00 Start]]

Aufgaben 51.03, 51.05 und 51.12 (Zusatzaufgaben vom 23.10.2026). Das Aufgabenblatt selbst ist nicht im Vault, weil das Repository öffentlich ist.

## Die Regeln, die man immer braucht
- **Gesetzliche Gewinnreserve:** 5 % des **Jahresgewinns**, bis die gesetzlichen Reserven zusammen 50 % des Aktienkapitals erreichen (Art. 672 OR). Es zählt nur der Jahresgewinn, nicht der alte Gewinnvortrag.
- **Verrechnungssteuer (VSt):** 35 % der Dividende. Die AG zahlt den Aktionären nur 65 % aus und überweist die 35 % der Steuerverwaltung (ESTV).
- **Agio** bei einer Kapitalerhöhung kommt in die **gesetzliche Kapitalreserve** (Art. 671 OR).

> [!note] Altes Recht
> Vor 2023 gab es zusätzlich eine «zweite Zuweisung» von 10 % der Dividende über 5 %. Die gilt heute nicht mehr. Aufgabe 51.05 lässt sich nur mit dem neuen Recht lösen (das Aktienkapital ist nicht angegeben), also rechnen wir überall mit 5 % des Jahresgewinns.

## 51.03 Zentral-Drogerie AG

Der Jahresgewinn von 40 steckt bereits im Gewinnvortrag von 44 (alter Vortrag 4 + Gewinn 40).

### Gewinnverwendungsplan per 20.3.2003

| Position | Betrag |
| --- | ---: |
| Gewinnvortrag per 31.12.2002 | 44 |
| − Zuwendung an gesetzliche Gewinnreserven (5 % von 40) | 2 |
| − Zuwendung an freiwillige Gewinnreserven | 20 |
| − Dividende 20 % (von 100 Aktienkapital) | 20 |
| **= neuer Gewinnvortrag** | **2** |

Die Zuwendung an die **freiwilligen** Reserven ist auf dem Blatt nicht vorgegeben. Die GV kann sie frei festlegen. Üblich ist ein runder Betrag, sodass ein kleiner Rest als Vortrag bleibt: 44 − 2 − 20 = 22, davon 20 in die freiwilligen Reserven und 2 als neuer Vortrag. Falls die Lehrperson einen anderen Betrag will, ändert sich nur der neue Gewinnvortrag.

### A. Eigenkapital nach der Gewinnverwendung

| Eigenkapital | |
| --- | ---: |
| Aktienkapital | 100 |
| Gesetzliche Gewinnreserve (30 + 2) | 32 |
| Freiwillige Gewinnreserven (46 + 20) | 66 |
| Gewinnvortrag | 2 |
| **= Eigenkapital** | **200** |

Das Eigenkapital sinkt von 220 auf 200, also genau um die **Dividende**. Reserven bilden ist nur eine Umbuchung innerhalb des Eigenkapitals.

### B. Verbuchung

Dividende 20 → VSt 35 % = 7, Auszahlung an die Aktionäre 65 % = 13.

| Datum | Text | Buchung | Betrag |
| --- | --- | --- | ---: |
| 20.03. | Gesetzliche Reserven | Gewinnvortrag / Gesetzliche Gewinnreserve | 2 |
| 20.03. | Freiwillige Reserven | Gewinnvortrag / Freiwillige Gewinnreserven | 20 |
| 20.03. | Dividendenzuweisung | Gewinnvortrag / Dividenden | 20 |
| 26.03. | Verrechnungssteuer | Dividenden / Verbindlichkeit VSt | 7 |
| 26.03. | Zahlung Dividende | Dividenden / Bank | 13 |
| 19.04. | Zahlung VSt | Verbindlichkeit VSt / Bank | 7 |

**Konten:**

| | Dividenden | Ges. Gewinnres. | Freiw. Gewinnres. | Gewinnvortrag |
| --- | --- | --- | --- | --- |
| 01.01. Anfangsbestand | – | H 30 | H 46 | H 44 |
| 20.03. Gesetzliche Reserven | | H 2 | | S 2 |
| 20.03. Freiwillige Reserven | | | H 20 | S 20 |
| 20.03. Dividendenzuweisung | H 20 | | | S 20 |
| 26.03. Verrechnungssteuer | S 7 | | | |
| 26.03. Zahlung Dividende | S 13 | | | |
| **19.04. Neue Bestände** | **0** | **32** | **66** | **2** |

(S = Soll, H = Haben. Die Reserven- und Vortragskonten sind Passivkonten, Zunahmen stehen also im Haben.)

### Weitere Fragen
- **A. Flüssige Mittel:** Sie sinken um die ganze Dividende von **20** (13 an die Aktionäre + 7 an die ESTV), also von 30 auf **10**. Die Reservenbildung kostet kein Geld, weil nichts ausbezahlt wird.
- **B. Problem ohne freiwillige Reserven:** Ohne Reserven wären die Gewinne früherer Jahre als Dividende ausbezahlt worden. Dann hätte die AG zu wenig flüssige Mittel gehabt und sich mehr Geld leihen müssen, um z. B. ihre Sachanlagen zu finanzieren. Behaltene Gewinne sind **Selbstfinanzierung**: Das Geld bleibt im Unternehmen. Schon jetzt bleiben nach der Dividende nur noch 10 flüssige Mittel.

## 51.03 Amido GmbH (Dividende beim Aktionär)
- Dividende pro Aktie: 20 % von CHF 1000 = CHF 200
- Amido besitzt 20 Aktien → Bruttodividende **CHF 4000**
- VSt 35 % = **CHF 1400**, Bankgutschrift 65 % = **CHF 2600**

| Buchung | Betrag |
| --- | ---: |
| Bank / Beteiligungsertrag | 2600 |
| Forderung VSt / Beteiligungsertrag | 1400 |

Die GmbH bucht als Ertrag die **ganze** Dividende (4000). Die VSt ist für sie eine Forderung, weil sie die 1400 von der ESTV zurückverlangen kann.

## 51.05 Cosinus AG

### A. Verbuchung des Jahresgewinns Ende 2006
**Erfolgsrechnung / Gewinnvortrag 160**

Der Gewinn wird aus der Erfolgsrechnung in die Bilanz übertragen. Der Gewinnvortrag steigt dadurch von 15 auf 175. (Führt ihr in der Bilanz ein eigenes Konto «Jahresgewinn», lautet die Buchung später: Jahresgewinn / Gewinnvortrag 160.)

### B. Gewinnverwendungsplan (GV 14. Mai 2007)

| Position | Betrag |
| --- | ---: |
| Gewinnvortrag inkl. Jahresgewinn (15 + 160) | 175 |
| − Zuwendung an gesetzliche Gewinnreserve (5 % von 160) | 8 |
| − Dividende | 160 |
| **= neuer Gewinnvortrag** | **7** |

### C. Buchungen für die Gewinnverwendung
VSt 35 % von 160 = 56, Auszahlung 65 % = 104.

| Buchung | Betrag |
| --- | ---: |
| Gewinnvortrag / Gesetzliche Gewinnreserve | 8 |
| Gewinnvortrag / Dividenden | 160 |
| Dividenden / Verbindlichkeit VSt | 56 |
| Dividenden / Bank | 104 |
| Verbindlichkeit VSt / Bank (Überweisung an die ESTV) | 56 |

### D. Buchung bei der Hauptaktionärin Sinus AG (75 %)
- Bruttodividende: 75 % von 160 = **120**
- VSt 35 % = **42**, Bankgutschrift = **78**

| Buchung | Betrag |
| --- | ---: |
| Bank / Beteiligungsertrag | 78 |
| Forderung VSt / Beteiligungsertrag | 42 |

> [!tip] Für Interessierte
> Bei grossen Beteiligungen zwischen Schweizer Gesellschaften gibt es in der Praxis das **Meldeverfahren**: Die VSt wird dann gar nicht abgezogen, und die Sinus AG würde direkt Bank / Beteiligungsertrag 120 buchen. In der Schule rechnet man aber meist mit dem normalen Abzug wie oben.

## 51.12 Athena AG (Kapitalerhöhung mit Agio)
- Nennwert: **300**
- Agio 20 % von 300 = **60**
- Die Aktionäre zahlen also **360** ein.

**Mit Zwischenkonto «Aktionäre»** (so in den meisten Lehrmitteln):

| Buchung | Betrag |
| --- | ---: |
| Aktionäre / Aktienkapital | 300 |
| Aktionäre / Gesetzliche Kapitalreserve | 60 |
| Bank / Aktionäre | 360 |

**Vereinfacht ohne Zwischenkonto:**

| Buchung | Betrag |
| --- | ---: |
| Bank / Aktienkapital | 300 |
| Bank / Gesetzliche Kapitalreserve | 60 |

Wichtig: Ins **Aktienkapital** kommt immer nur der **Nennwert**. Das Agio (der Aufpreis über dem Nennwert) gehört in die **gesetzliche Kapitalreserve** (Art. 671 Abs. 1 Ziff. 1 OR).
